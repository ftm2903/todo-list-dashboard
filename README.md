# Todo List Dashboard

A fully responsive todo list dashboard featuring inline editing, task status management, localStorage persistence, and custom validation modal.

## 🚀 Features

- **Inline Editing:** Edit task title, date, time, and tag directly inside the table.
- **Task Management:** Add, delete, and update todo items with smooth user interaction.
- **Status Tracking:** Manage task states such as Not Started, In Progress, and Done.
- **Data Persistence:** Save tasks in localStorage so data remains after page refresh.
- **Custom Validation:** Uses a custom modal instead of default alert messages.
- **Responsive Design:** Optimized layout for desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3 (Flexbox/Grid/Media Queries)**
- **Vanilla JavaScript (ES6+)**
- **LocalStorage**
- **Font Awesome** (for icons)
- **Flatpickr** (for date/time picking, if used in your project)

1. Clone the repository to your local machine.
2. Make sure all required files and assets are included.
3. Open index.html in your browser.
